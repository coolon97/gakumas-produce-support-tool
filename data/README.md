# データについて

このディレクトリには、本ツールが参照するJSONデータを収録しています。
本データはゲーム画面から確認できる情報を非公式に作成・整理したものであり、ゲームの運営元・権利者による提供や公認を受けたものではありません。
よって、このディレクトリのJSONデータにはBSD 3-Clause Licenseを適用しません。

## 第三者の権利

ゲーム内の文章・名称・画像など、第三者が権利を有する内容の権利は、それぞれの権利者に帰属します。

- `cards.json`
- `idols.json`

## 正確性について

データの正確性・完全性・最新性は保証しません。ゲームの更新等により、実際の内容と異なる場合があります。
誤りを発見した場合は、確認できる根拠とともに本リポジトリのIssuesへお知らせください。
