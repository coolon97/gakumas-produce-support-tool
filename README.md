# 学マス H.I.F評価 理論値 計算ツール

学園アイドルマスターのプロデュースシナリオ「H.I.F」における、プロデュース評価の理論値計算ツールです。

## 開発・ビルド

Node.js 22以降とnpmが必要です。

```sh
npm ci
npm run dev
npm test
```

```sh
npm run build
npm run preview
```

ビルド結果は `dist/` に生成されます。
